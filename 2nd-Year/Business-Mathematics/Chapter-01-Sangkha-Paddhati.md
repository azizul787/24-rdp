## অংশ ক — সহজ ব্যাখ্যা

### সংখ্যা পদ্ধতি কী?

> ধরো তুমি বাজারে গেলে। দোকানদার বলল — "আলু ১ কেজি ৪০ টাকা।"
> এখানে **১**, **৪০** — এগুলো সংখ্যা।
> কিন্তু সব সংখ্যা কি একরকম? না! সংখ্যা অনেক ধরনের হয়।
> এই অধ্যায়ে আমরা শিখব সংখ্যার বিভিন্ন প্রকার এবং তাদের নিয়মকানুন।

### সংখ্যার প্রকারভেদ (সহজ ভাষায়)

```
                        সংখ্যা
                          |
          --------------------------------
          |                              |
     বাস্তব সংখ্যা (Real)          কাল্পনিক সংখ্যা (Imaginary)
          |                         যেমন: √(-1) = i
     -----------------
     |               |
  মূলদ (Rational)  অমূলদ (Irrational)
     |
  --------
  |      |
পূর্ণসংখ্যা  ভগ্নাংশ
  |
-----
|   |
ধনাত্মক  ঋণাত্মক  শূন্য
```

### মূলদ সংখ্যা কী?

> যে সংখ্যাকে **p/q** আকারে লেখা যায় (যেখানে p ও q পূর্ণসংখ্যা এবং q ≠ 0), তাকে মূলদ সংখ্যা বলে।
>
> **উদাহরণ:** ½, ¾, 5, -3, 0, 0.25

### অমূলদ সংখ্যা কী?

> যে সংখ্যাকে **p/q** আকারে লেখা **যায় না**, তাকে অমূলদ সংখ্যা বলে।
>
> **উদাহরণ:** √2, √3, √5, √7, √11, π (পাই)

> [!TIP]
> **মনে রাখার কৌশল:**
> মূলদ = ভাগ করা **যায়** (p/q হয়)
> অমূলদ = ভাগ করা **যায় না** (p/q হয় না)

## অংশ খ — পরীক্ষার উত্তর (NU Pattern)

---

### প্রশ্ন ১: মূলদ ও অমূলদ সংখ্যা কী? পার্থক্য লেখো। `[নম্বর: ৫-১০]`

#### ভূমিকা
সংখ্যাতত্ত্বে বাস্তব সংখ্যাকে দুটি প্রধান ভাগে ভাগ করা হয় — মূলদ ও অমূলদ সংখ্যা। ব্যবসায়িক গণনায় এই দুই ধরনের সংখ্যার সঠিক ধারণা অত্যন্ত গুরুত্বপূর্ণ।

#### মূলদ সংখ্যার সংজ্ঞা
যে সংখ্যাকে **p/q** আকারে প্রকাশ করা যায়, যেখানে p ও q উভয়ই পূর্ণসংখ্যা এবং q ≠ 0, তাকে **মূলদ সংখ্যা** বলে।

**উদাহরণ:** ½, ¾, 5 (= 5/1), -3, 0, 0.5 (= ½)

#### অমূলদ সংখ্যার সংজ্ঞা
যে সংখ্যাকে p/q আকারে প্রকাশ **করা যায় না** এবং যার দশমিক প্রসার অসীম ও পুনরাবৃত্তিহীন, তাকে **অমূলদ সংখ্যা** বলে।

**উদাহরণ:** √2 = 1.41421356..., √3, √5, π = 3.14159...

#### পার্থক্য

| বিষয় | মূলদ সংখ্যা | অমূলদ সংখ্যা |
|-------|------------|--------------|
| সংজ্ঞা | p/q আকারে প্রকাশযোগ্য | p/q আকারে প্রকাশযোগ্য নয় |
| দশমিক | সীমিত বা পুনরাবৃত্তিমূলক | অসীম ও পুনরাবৃত্তিহীন |
| উদাহরণ | ½, ¾, 5, -3 | √2, √3, π |
| সংখ্যারেখায় | প্রতিটি বিন্দুতে আছে | দুই মূলদ সংখ্যার মাঝে আছে |

#### উপসংহার
মূলদ ও অমূলদ সংখ্যা একসাথে **বাস্তব সংখ্যা (Real Number)** গঠন করে। ব্যবসায়িক হিসাব-নিকাশে সাধারণত মূলদ সংখ্যা ব্যবহৃত হয়।



---

### প্রশ্ন ২: অমূলদ সংখ্যার প্রমাণ — √2, √3, √5 অমূলদ তা প্রমাণ করো। `[নম্বর: ১০]`

#### ভূমিকা
অমূলদ সংখ্যার প্রমাণ গণিতের একটি গুরুত্বপূর্ণ অংশ। বিপরীতমুখী প্রমাণ (Proof by Contradiction) পদ্ধতিতে এটি প্রমাণ করা হয়।

#### প্রমাণ: √2 অমূলদ সংখ্যা

**ধরি,** √2 একটি মূলদ সংখ্যা।
তাহলে √2 = p/q লেখা যাবে, যেখানে p ও q সহমৌলিক পূর্ণসংখ্যা (অর্থাৎ তাদের মধ্যে ১ ছাড়া অন্য কোনো সাধারণ গুণনীয়ক নেই) এবং q ≠ 0।

**ধাপ ১:** উভয় পক্ষ বর্গ করি —
2 = p²/q²
∴ p² = 2q² ... (i)

**ধাপ ২:** সমীকরণ (i) থেকে বোঝা যায় p² সংখ্যাটি **জোড়** (কারণ 2q² জোড়)।
যদি p² জোড় হয়, তাহলে p-ও জোড়।
সুতরাং, p = 2m ধরা যায় (m একটি পূর্ণসংখ্যা)।

**ধাপ ৩:** p = 2m সমীকরণ (i)-এ বসাই —
(2m)² = 2q²
4m² = 2q²
∴ q² = 2m²

এর মানে q²-ও জোড়, তাই q-ও জোড়।

**ধাপ ৪:** এখন দেখা যাচ্ছে p ও q উভয়ই জোড় — অর্থাৎ উভয়ের সাধারণ গুণনীয়ক ২ আছে।
কিন্তু আমরা শুরুতে ধরেছিলাম p ও q সহমৌলিক — **এটি বিরোধাভাস!**

**উপসংহার:** আমাদের প্রাথমিক অনুমান (√2 মূলদ) ভুল।
∴ **√2 একটি অমূলদ সংখ্যা।** (প্রমাণিত)

> [!TIP]
> **পরীক্ষায় টিপস:** √3 ও √5 এর প্রমাণও একই পদ্ধতিতে হয়। শুধু সংখ্যা বদলে দাও।

---

### প্রশ্ন ৩: বীজগাণিতিক সূত্রাবলি লেখো ও প্রমাণ করো। `[নম্বর: ১০]`

#### গুরুত্বপূর্ণ বীজগাণিতিক সূত্রাবলি

| # | সূত্র |
|---|-------|
| ১ | (a + b)² = a² + 2ab + b² |
| ২ | (a - b)² = a² - 2ab + b² |
| ৩ | (a + b)² = (a - b)² + 4ab |
| ৪ | (a - b)² = (a + b)² - 4ab |
| ৫ | a² - b² = (a + b)(a - b) |
| ৬ | (a + b)³ = a³ + 3a²b + 3ab² + b³ |
| ৭ | (a - b)³ = a³ - 3a²b + 3ab² - b³ |
| ৮ | a³ + b³ = (a + b)(a² - ab + b²) |
| ৯ | a³ - b³ = (a - b)(a² + ab + b²) |
| ১০ | (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca |

#### প্রমাণ: (a + b)² = a² + 2ab + b²

LHS = (a + b)²
= (a + b)(a + b)
= a(a + b) + b(a + b)
= a² + ab + ba + b²
= a² + 2ab + b²
= RHS ✓ **(প্রমাণিত)**

#### প্রমাণ: a² - b² = (a + b)(a - b)

RHS = (a + b)(a - b)
= a(a - b) + b(a - b)
= a² - ab + ab - b²
= a² - b²
= LHS ✓ **(প্রমাণিত)**

## অংশ গ — ধাপে ধাপে সমাধান

> [!IMPORTANT]
> **পরীক্ষায় গণিত লেখার নিয়ম:**
> **দেওয়া আছে → নির্ণেয় → সূত্র → সমাধান → উত্তর**

---

### সমস্যা ১: √2 অমূলদ প্রমাণ করো।
*(উপরে বিস্তারিত প্রমাণ দেওয়া আছে — অধ্যায় খ, প্রশ্ন ২ দেখো)*

---

### সমস্যা ২: সূত্র ব্যবহার করে মান নির্ণয়

**প্রশ্ন:** যদি a + b = 7 এবং ab = 12 হয়, তাহলে a² + b² এবং (a - b) নির্ণয় করো।

**দেওয়া আছে:** a + b = 7, ab = 12

**নির্ণেয়:** a² + b², (a - b)

**সমাধান:**

**ধাপ ১:** a² + b² নির্ণয়
সূত্র: (a + b)² = a² + 2ab + b²
∴ a² + b² = (a + b)² - 2ab
= (7)² - 2(12)
= 49 - 24
= **25**

**ধাপ ২:** (a - b) নির্ণয়
সূত্র: (a - b)² = (a + b)² - 4ab
= (7)² - 4(12)
= 49 - 48
= 1
∴ (a - b) = √1 = **1**

**উত্তর:** a² + b² = 25 এবং (a - b) = 1

---

### সমস্যা ৩: ঘনের সূত্র ব্যবহার

**প্রশ্ন:** যদি a + b = 5 এবং ab = 6 হয়, তাহলে a³ + b³ নির্ণয় করো।

**দেওয়া আছে:** a + b = 5, ab = 6

**নির্ণেয়:** a³ + b³

**সমাধান:**
সূত্র: a³ + b³ = (a + b)³ - 3ab(a + b)
= (5)³ - 3(6)(5)
= 125 - 90
= **35**

**উত্তর:** a³ + b³ = 35

---

### সমস্যা ৪: জটিল সংখ্যা

**প্রশ্ন:** (3 + 2i)(3 - 2i) এর মান নির্ণয় করো।

**সমাধান:**
সূত্র: (a + b)(a - b) = a² - b²
= (3)² - (2i)²
= 9 - 4i²
= 9 - 4(-1)      [কারণ i² = -1]
= 9 + 4
= **13**

**উত্তর:** 13

---

### অনুশীলনী সমস্যা (নিজে চেষ্টা করো)

> [!NOTE]
> আগে নিজে চেষ্টা করো, তারপর উত্তর দেখো।

**P1.** যদি x - y = 4 এবং xy = 21 হয়, তাহলে x² + y² নির্ণয় করো।
<details><summary>উত্তর দেখো</summary>
x² + y² = (x-y)² + 2xy = 16 + 42 = <b>58</b>
</details>

**P2.** যদি a + b = 6 এবং a - b = 2 হয়, তাহলে ab নির্ণয় করো।
<details><summary>উত্তর দেখো</summary>
4ab = (a+b)² - (a-b)² = 36 - 4 = 32, ∴ ab = <b>8</b>
</details>

**P3.** √3 অমূলদ সংখ্যা তা প্রমাণ করো।
<details><summary>উত্তর দেখো</summary>
√2 এর প্রমাণের মতো একই পদ্ধতিতে করো। ধরো √3 = p/q, তাহলে p² = 3q²। এতে p ও q উভয়ই 3 দ্বারা বিভাজ্য হয় — বিরোধাভাস। ∴ √3 অমূলদ।
</details>

## অংশ ঙ — সংক্ষিপ্ত প্রশ্ন (৪ নম্বর)

> [!NOTE]
> ৪ নম্বরের জন্য: **সংজ্ঞা + ২-৩টি বৈশিষ্ট্য + একটি উদাহরণ** = পূর্ণ নম্বর

১. মূলদ ও অমূলদ সংখ্যার সংজ্ঞা দাও।
২. বাস্তব সংখ্যা কী? এর প্রকারভেদ লেখো।
৩. কাল্পনিক সংখ্যা কী? i, i², i³, i⁴ এর মান লেখো।
৪. (a+b)² = a²+2ab+b² প্রমাণ করো।
৫. a²-b² = (a+b)(a-b) প্রমাণ করো।

## ⭐ দ্রুত পুনরালোচনা কার্ড

> [!IMPORTANT]
> পরীক্ষার আগের রাতে শুধু এই টেবিলটি পড়ো।

| বিষয় | মনে রাখো |
|-------|----------|
| মূলদ সংখ্যা | p/q আকারে লেখা যায়; উদাহরণ: ½, 5, -3 |
| অমূলদ সংখ্যা | p/q আকারে লেখা যায় না; উদাহরণ: √2, √3, π |
| i এর মান | i = √(-1), i² = -1, i³ = -i, i⁴ = 1 |
| (a+b)² | a² + 2ab + b² |
| (a-b)² | a² - 2ab + b² |
| a²-b² | (a+b)(a-b) |
| a³+b³ | (a+b)(a²-ab+b²) |
| a³-b³ | (a-b)(a²+ab+b²) |
| (a+b)³ | a³+3a²b+3ab²+b³ |
| (a+b+c)² | a²+b²+c²+2ab+2bc+2ca |

### মনে রাখার কৌশল

> **কৌশল ১ — বর্গের সূত্র:**
> (a+b)² → প্রথম বর্গ + দ্বিগুণ গুণফল + শেষ বর্গ
> (a-b)² → একই কিন্তু মাঝে বিয়োগ

> **কৌশল ২ — ঘনের চিহ্ন:**
> (a+b)³ → সব যোগ
> (a-b)³ → পর্যায়ক্রমে (+, -, +, -)
