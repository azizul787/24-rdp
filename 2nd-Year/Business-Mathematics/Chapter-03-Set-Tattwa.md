## অংশ ক — সহজ ব্যাখ্যা

### সেট কী?

> তোমার মায়ের রান্নাঘরে একটা ঝুড়িতে আছে — আম, কলা, আপেল।
> আরেকটা ঝুড়িতে আছে — আলু, পেঁয়াজ, টমেটো।
>
> প্রতিটা ঝুড়ি হলো একটা **সেট**।
> ঝুড়ির ভেতরের প্রতিটা জিনিস হলো **উপাদান (element)**।

> [!TIP]
> **সেট = একই ধরনের বা নির্দিষ্ট গুণের জিনিসের সুসংগঠিত সমাবেশ।**
> প্রতিটা জিনিস আলাদা হতে হবে — একই জিনিস দুবার থাকবে না।

### সেট লেখার দুটো পদ্ধতি

| পদ্ধতি | কীভাবে লেখে | উদাহরণ |
|--------|------------|---------|
| **তালিকা পদ্ধতি (Roster)** | সব উপাদান { } এর মধ্যে লেখো | A = {1, 2, 3, 4, 5} |
| **সেট-নির্মাতা পদ্ধতি (Set-builder)** | নিয়ম বা শর্ত লেখো | A = {x : x ≤ 5, x প্রাকৃতিক সংখ্যা} |

### প্রশ্ন ১: সেটের সংজ্ঞা ও প্রকারভেদ আলোচনা করো। `[নম্বর: ১০]`

#### ভূমিকা
সেট তত্ত্ব আধুনিক গণিতের ভিত্তি। জার্মান গণিতবিদ **গেওর্গ ক্যান্টর (Georg Cantor, ১৮৪৫–১৯১৮)** সেট তত্ত্ব উদ্ভাবন করেন। ব্যবসায়িক গণিতে সেট তত্ত্ব ব্যবহার করে জরিপ বিশ্লেষণ, বাজার বিভাজন ইত্যাদি করা হয়।

#### সেটের সংজ্ঞা
> **ক্যান্টর:** "সেট হলো সুনির্দিষ্ট ও পৃথক বস্তুর সমাহার।"

সহজ কথায়: **সুনির্দিষ্ট গুণসম্পন্ন ও পরস্পর আলাদা উপাদানের সমষ্টিকে সেট বলে।**

তিনটি মূল শর্ত:
1. **সুনির্দিষ্ট (Well-defined):** কোনো উপাদান সেটে আছে কি নেই তা স্পষ্টভাবে বলা যাবে।
2. **পৃথক (Distinct):** কোনো উপাদান দুইবার থাকবে না।
3. **সমাহার (Collection):** একাধিক জিনিসের গ্রুপ।

#### সেটের প্রকারভেদ

| # | প্রকার | সংজ্ঞা | উদাহরণ |
|---|--------|--------|--------|
| ১ | **ফাঁকা সেট (Empty Set)** | কোনো উপাদান নেই | A = { } বা ∅ |
| ২ | **একক সেট (Singleton)** | মাত্র একটি উপাদান | A = {5} |
| ৩ | **পরিমিত সেট (Finite Set)** | গণনাযোগ্য উপাদান | A = {1, 2, 3, 4} |
| ৪ | **অপরিমিত সেট (Infinite Set)** | অগণ্য উপাদান | N = {1, 2, 3, ...} |
| ৫ | **সমান সেট (Equal Sets)** | একই উপাদান | A={1,2,3}, B={3,2,1} → A=B |
| ৬ | **সমতুল্য সেট (Equivalent)** | সমান সংখ্যক উপাদান | A={1,2,3}, B={a,b,c} |
| ৭ | **উপসেট (Subset ⊆)** | A-এর সব উপাদান B-তে আছে | {1,2} ⊆ {1,2,3} |
| ৮ | **সার্বিক সেট (Universal Set U)** | আলোচ্য সব উপাদানের সেট | সব NU শিক্ষার্থী |
| ৯ | **শক্তি সেট (Power Set P(A))** | A-এর সব সম্ভব উপসেটের সেট | A={1,2} → P(A)={∅,{1},{2},{1,2}} |
| ১০ | **বিচ্ছিন্ন সেট (Disjoint)** | কোনো সাধারণ উপাদান নেই | A={1,2}, B={3,4} |

> **গুরুত্বপূর্ণ সূত্র:** n উপাদানের সেটের মোট উপসেট = **2ⁿ**

#### উপসংহার
সেটের প্রকারভেদ জানা থাকলে সেট অপারেশন ও ভেনচিত্র সহজে বোঝা যায়।

### প্রশ্ন ২: সেট অপারেশন ও ভেনচিত্র ব্যাখ্যা করো। `[নম্বর: ১০]`

#### ভূমিকা
দুটি বা তার বেশি সেটকে বিভিন্নভাবে একত্রিত বা তুলনা করার প্রক্রিয়াকে সেট অপারেশন বলে।

ধরি, **A = {1, 2, 3, 4}** এবং **B = {3, 4, 5, 6}**

#### ১. মিলন (Union — A ∪ B) — "অথবা"
A ও B-এর **সব উপাদান** একসাথে (একই উপাদান একবার লেখা হয়)।
> A ∪ B = {1, 2, 3, 4, 5, 6}
> **ভেনচিত্র:** দুটো বৃত্তের সম্পূর্ণ অংশ

#### ২. ছেদ (Intersection — A ∩ B) — "এবং"
A ও B-এর **সাধারণ উপাদান**।
> A ∩ B = {3, 4}
> **ভেনচিত্র:** দুটো বৃত্তের মাঝের অংশ

#### ৩. পার্থক্য (Difference — A − B)
A-তে আছে কিন্তু B-তে **নেই** এমন উপাদান।
> A − B = {1, 2}  &nbsp;&nbsp;  B − A = {5, 6}

#### ৪. পূরক (Complement — A')
সার্বিক সেট U-এ আছে কিন্তু A-তে **নেই** এমন উপাদান।
> যদি U = {1,...,7}, A = {1,2,3} হয়, তাহলে A' = {4, 5, 6, 7}

#### ৫. প্রতিসম পার্থক্য (Symmetric Difference — A △ B)
> A △ B = (A − B) ∪ (B − A) = {1, 2, 5, 6}

#### সারসংক্ষেপ টেবিল

| অপারেশন | চিহ্ন | অর্থ | উদাহরণ |
|---------|-------|------|--------|
| মিলন | A ∪ B | সব উপাদান | {1,2,3,4,5,6} |
| ছেদ | A ∩ B | সাধারণ উপাদান | {3,4} |
| পার্থক্য | A − B | শুধু A-তে | {1,2} |
| পূরক | A' | A-তে নেই | U এর উপর নির্ভর করে |

#### উপসংহার
এই পাঁচটি অপারেশন সেট তত্ত্বের মূল হাতিয়ার। ব্যবসায়িক জরিপ বিশ্লেষণে এগুলো সরাসরি প্রয়োগ করা হয়।

---

### প্রশ্ন ৩: ডি মর্গানের সূত্র লেখো ও প্রমাণ করো। `[নম্বর: ১০]`

#### ভূমিকা
ব্রিটিশ গণিতবিদ **অগাস্টাস ডি মর্গান** সেট বীজগণিতের দুটি গুরুত্বপূর্ণ সূত্র প্রদান করেন।

#### ডি মর্গানের সূত্রদ্বয়

> **সূত্র ১:** (A ∪ B)' = A' ∩ B'
> **সূত্র ২:** (A ∩ B)' = A' ∪ B'

#### প্রমাণ: সূত্র ১ — (A ∪ B)' = A' ∩ B'

**দেওয়া আছে:** U = {1,2,3,4,5,6,7,8}, A = {1,2,3,4}, B = {3,4,5,6}

**বাম পক্ষ (LHS):**
A ∪ B = {1, 2, 3, 4, 5, 6}
(A ∪ B)' = U − (A ∪ B) = {7, 8}

**ডান পক্ষ (RHS):**
A' = {5, 6, 7, 8}
B' = {1, 2, 7, 8}
A' ∩ B' = {7, 8}

**যেহেতু LHS = RHS = {7, 8}, সূত্র ১ প্রমাণিত। ✓**

> [!TIP]
> **মনে রাখার কৌশল (ডি মর্গান):**
> ড্যাশ (') ভেতরে গেলে চিহ্ন পাল্টায়:
> (A ∪ B)' → A' **∩** B' (∪ হয়ে যায় ∩)
> (A ∩ B)' → A' **∪** B' (∩ হয়ে যায় ∪)

## অংশ গ — ধাপে ধাপে সমাধান

### সমস্যা ১: দুটো সেটের জরিপ সমস্যা

**প্রশ্ন:** একটি ক্লাসে ৫০ জন ছাত্র। ৩০ জন ক্রিকেট খেলে, ২৫ জন ফুটবল খেলে এবং ১০ জন উভয়ই খেলে। কতজন অন্তত একটি খেলা খেলে? কতজন কোনোটাই খেলে না?

**দেওয়া আছে:**
- মোট = 50
- n(C) = 30, n(F) = 25, n(C ∩ F) = 10

**নির্ণেয়:** n(C ∪ F) এবং কেউ খেলে না

**সূত্র:** n(C ∪ F) = n(C) + n(F) − n(C ∩ F)

**সমাধান:**
n(C ∪ F) = 30 + 25 − 10 = **45**

কেউ খেলে না = 50 − 45 = **5**

**উত্তর:** ৪৫ জন অন্তত একটি খেলা খেলে। ৫ জন কোনো খেলাই খেলে না।

---

### সমস্যা ২: তিনটো সেটের জরিপ সমস্যা (★ প্রতিবছর আসে!)

**প্রশ্ন:** একটি সুপারশপে ১০০ জন ক্রেতার জরিপে পাওয়া গেল:
- ৬০ জন চাল কিনেছে (R)
- ৫০ জন তেল কিনেছে (O)
- ৪০ জন চিনি কিনেছে (S)
- ২৫ জন চাল ও তেল উভয় কিনেছে
- ২০ জন তেল ও চিনি উভয় কিনেছে
- ১৫ জন চাল ও চিনি উভয় কিনেছে
- ১০ জন তিনটাই কিনেছে

নির্ণয় করো: (i) অন্তত একটি কিনেছে (ii) কেউ কিছু কিনেনি

**দেওয়া আছে:**
- n(R)=60, n(O)=50, n(S)=40
- n(R∩O)=25, n(O∩S)=20, n(R∩S)=15
- n(R∩O∩S)=10, মোট=100

**সূত্র:**
n(R∪O∪S) = n(R)+n(O)+n(S) − n(R∩O) − n(O∩S) − n(R∩S) + n(R∩O∩S)

**সমাধান:**
n(R∪O∪S) = 60+50+40 − 25−20−15 + 10
= 150 − 60 + 10
= **100**

কেউ কিছু কিনেনি = 100 − 100 = **0**

**উত্তর:** (i) ১০০ জনই অন্তত একটি পণ্য কিনেছে। (ii) কেউ কিছু কিনেনি: ০ জন।

### সমস্যা ৩: শক্তি সেট নির্ণয়

**প্রশ্ন:** A = {a, b, c} হলে P(A) নির্ণয় করো।

**সমাধান:**
মোট উপসেট = 2³ = 8

P(A) = { ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c} }

**উত্তর:** P(A)-এ ৮টি উপসেট আছে।

|-------|----------|
| সেট উদ্ভাবক | **Georg Cantor** |
| উপসেট সংখ্যা | **2ⁿ** (n = উপাদান সংখ্যা) |
| মিলন (∪) | সব উপাদান একসাথে |
| ছেদ (∩) | শুধু সাধারণ উপাদান |
| পূরক (A') | U-তে আছে, A-তে নেই |
| n(A∪B) | n(A) + n(B) − n(A∩B) |
| n(A∪B∪C) | n(A)+n(B)+n(C)−n(A∩B)−n(B∩C)−n(A∩C)+n(A∩B∩C) |
| ডি মর্গান ১ | (A∪B)' = A'∩B' |
| ডি মর্গান ২ | (A∩B)' = A'∪B' |

### মনে রাখার কৌশল

> **∪ vs ∩:**
> ∪ দেখতে "U" এর মতো → **U**nion → সব মিলিয়ে নাও
> ∩ দেখতে উল্টো "U" → ভেতরের অংশ → শুধু সাধারণটা

> **তিন সেটের সূত্র চিহ্ন:**
> **+ + + − − − +** (তিনটা যোগ, তিনটা বিয়োগ, একটা যোগ)
