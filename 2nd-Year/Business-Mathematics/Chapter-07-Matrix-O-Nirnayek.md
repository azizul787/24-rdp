## অংশ ক — সহজ ব্যাখ্যা

### ম্যাট্রিক্স কী?

> ধরো একটি স্কুলে ৩টি ক্লাসে পরীক্ষার নম্বর এভাবে সাজানো আছে:
>
> | ক্লাস | গণিত | বাংলা | ইংরেজি |
> |-------|------|-------|--------|
> | ৬ষ্ঠ | 80 | 75 | 70 |
> | ৭ম | 85 | 80 | 78 |
> | ৮ম | 90 | 85 | 82 |
>
> এই সংখ্যাগুলোকে **[ ]** বন্ধনীতে সাজিয়ে রাখলেই হলো **ম্যাট্রিক্স**।
> প্রতিটি সংখ্যা হলো একটি **উপাদান (element)**।
> সারি (row) → আড়াআড়ি; কলাম (column) → উপর-নিচ।

> [!TIP]
> **m × n ম্যাট্রিক্স** মানে m সারি এবং n কলাম।
> উপাদান aᵢⱼ মানে i-তম সারি ও j-তম কলামের উপাদান।

## ম্যাট্রিক্সের প্রকারভেদ

| প্রকার | সংজ্ঞা | উদাহরণ |
|--------|--------|--------|
| **সারি ম্যাট্রিক্স** | শুধু ১টি সারি | [1 2 3] |
| **কলাম ম্যাট্রিক্স** | শুধু ১টি কলাম | [1; 2; 3] |
| **বর্গ ম্যাট্রিক্স** | সারি = কলাম (n×n) | 2×2, 3×3 |
| **শূন্য ম্যাট্রিক্স** | সব উপাদান ০ | [0 0; 0 0] |
| **একক ম্যাট্রিক্স (I)** | কর্ণে ১, বাকি ০ | [1 0; 0 1] |
| **ট্রান্সপোজ (Aᵀ)** | সারি ও কলাম পাল্টানো | A এর সারি → কলাম |
| **সমান ম্যাট্রিক্স** | একই আকার ও একই উপাদান | A = B |
| **প্রতিসম ম্যাট্রিক্স** | A = Aᵀ | কর্ণের দুপাশ সমান |

## অংশ খ — পরীক্ষার উত্তর

### প্রশ্ন ১: ম্যাট্রিক্সের সংজ্ঞা, প্রকারভেদ ও অপারেশন আলোচনা করো। `[নম্বর: ১০]`

#### ভূমিকা
ম্যাট্রিক্স গণিতের একটি শক্তিশালী হাতিয়ার। ব্যবসায়িক তথ্য বিশ্লেষণ, একাধিক সমীকরণ সমাধান, অর্থনৈতিক মডেলিং, ইনপুট-আউটপুট বিশ্লেষণে ম্যাট্রিক্স অপরিহার্য।

#### ম্যাট্রিক্সের সংজ্ঞা
সংখ্যা বা রাশিমালাকে সারি ও কলামে সাজিয়ে বন্ধনীর ভেতরে রাখলে যা পাওয়া যায়, তাকে **ম্যাট্রিক্স** বলে।

m সারি ও n কলামবিশিষ্ট ম্যাট্রিক্সকে **m × n ম্যাট্রিক্স** বলে।

#### ম্যাট্রিক্স যোগের নিয়ম
একই আকারের দুটি ম্যাট্রিক্সের একই অবস্থানের উপাদান যোগ করতে হয়।

**উদাহরণ:**
```
A = [1 2]    B = [5 6]         A+B = [6  8]
    [3 4]        [7 8]               [10 12]
```

#### ম্যাট্রিক্স গুণের নিয়ম
A (m×n) ও B (n×p) হলে AB (m×p) হবে।
i-তম সারি ও j-তম কলামের উপাদান = A-এর i-তম সারি × B-এর j-তম কলাম (ডট গুণফল)।

> [!IMPORTANT]
> **AB ≠ BA** সাধারণত — ম্যাট্রিক্স গুণ পরিবর্তনীয় নয়!

#### উপসংহার
ম্যাট্রিক্স অপারেশন ব্যবহার করে একসাথে অনেক সমীকরণ দ্রুত সমাধান করা যায়।

---

### প্রশ্ন ২: নির্ণায়ক ও বিপরীত ম্যাট্রিক্স নির্ণয় করো। `[নম্বর: ১২]`

#### নির্ণায়কের সংজ্ঞা
প্রতিটি বর্গ ম্যাট্রিক্সের সাথে একটি বিশেষ সংখ্যা যুক্ত থাকে, তাকে **নির্ণায়ক (Determinant)** বলে। det(A) বা |A| দিয়ে প্রকাশ করা হয়।

#### 2×2 ম্যাট্রিক্সের নির্ণায়ক

```
যদি A = [a  b]  তাহলে |A| = ad - bc
         [c  d]
```

#### 3×3 ম্যাট্রিক্সের নির্ণায়ক (সারফাস বিস্তৃতি)

```
    |a₁ b₁ c₁|
    |a₂ b₂ c₂| = a₁(b₂c₃ - b₃c₂) - b₁(a₂c₃ - a₃c₂) + c₁(a₂b₃ - a₃b₂)
    |a₃ b₃ c₃|
```

#### বিপরীত ম্যাট্রিক্স (Inverse Matrix)

> **A⁻¹ = (1/|A|) × adj(A)**
>
> যেখানে adj(A) = A-এর সহগুণক ম্যাট্রিক্সের ট্রান্সপোজ

**শর্ত:** বিপরীত ম্যাট্রিক্স বিদ্যমান হতে হলে **|A| ≠ 0** হতে হবে।

## অংশ গ — ধাপে ধাপে সমাধান

### সমস্যা ১: ম্যাট্রিক্স যোগ ও গুণ

**প্রশ্ন:** যদি A = [[1,2],[3,4]] এবং B = [[5,6],[7,8]] হয়, তাহলে A+B ও AB নির্ণয় করো।

**A + B:**
```
[1+5  2+6]   [6   8]
[3+7  4+8] = [10  12]
```

**AB:**
```
[(1×5 + 2×7)  (1×6 + 2×8)]   [5+14   6+16]   [19  22]
[(3×5 + 4×7)  (3×6 + 4×8)] = [15+28  18+32] = [43  50]
```

---

### সমস্যা ২: নির্ণায়ক নির্ণয়

**প্রশ্ন:** A = [[3,1],[2,4]] হলে |A| নির্ণয় করো।

**সমাধান:**
|A| = (3×4) - (1×2)
= 12 - 2
= **10**

---

### সমস্যা ৩: বিপরীত ম্যাট্রিক্স

**প্রশ্ন:** A = [[4,2],[3,1]] হলে A⁻¹ নির্ণয় করো।

**ধাপ ১:** নির্ণায়ক নির্ণয়
|A| = (4×1) - (2×3) = 4 - 6 = **-2**

**ধাপ ২:** যেহেতু |A| = -2 ≠ 0, বিপরীত ম্যাট্রিক্স বিদ্যমান।

**ধাপ ৩:** 2×2 ম্যাট্রিক্সের বিপরীত সূত্র:
```
A⁻¹ = (1/|A|) × [d  -b]
                  [-c   a]
```

**ধাপ ৪:**
```
A⁻¹ = (1/-2) × [1  -2]  =  [-1/2   1  ]
                [-3   4]     [3/2   -2  ]
```

**উত্তর:** A⁻¹ = [[-1/2, 1], [3/2, -2]]

---

### সমস্যা ৪: ক্র্যামারের নিয়মে সমীকরণ সমাধান

**প্রশ্ন:** ক্র্যামারের নিয়মে সমাধান করো:
2x + y = 5
x + 3y = 10

**ধাপ ১:** সহগ ম্যাট্রিক্স ও নির্ণায়ক
```
A = [2  1]    |A| = (2×3) - (1×1) = 6 - 1 = 5
    [1  3]
```

**ধাপ ২:** x-এর জন্য Dₓ
```
Dₓ = [5   1]  = (5×3) - (1×10) = 15 - 10 = 5
     [10  3]
```

**ধাপ ৩:** y-এর জন্য Dᵧ
```
Dᵧ = [2   5]  = (2×10) - (5×1) = 20 - 5 = 15
     [1  10]
```

**ধাপ ৪:** x ও y নির্ণয়
x = Dₓ/|A| = 5/5 = **1**
y = Dᵧ/|A| = 15/5 = **3**

**উত্তর:** x = 1, y = 3

---

## ⭐ দ্রুত পুনরালোচনা কার্ড

| বিষয় | মনে রাখো |
|-------|----------|
| m×n ম্যাট্রিক্স | m = সারি, n = কলাম |
| একক ম্যাট্রিক্স (I) | কর্ণে 1, বাকি সব 0 |
| 2×2 নির্ণায়ক | \|A\| = ad - bc |
| বিপরীত শর্ত | \|A\| ≠ 0 হতে হবে |
| A × A⁻¹ | = I (একক ম্যাট্রিক্স) |
| AB ≠ BA | গুণ পরিবর্তনীয় নয় |
| ক্র্যামার: x | = Dₓ / \|A\| |
| ক্র্যামার: y | = Dᵧ / \|A\| |

### মনে রাখার কৌশল

> **2×2 নির্ণায়ক:**
> [a b; c d] → "কর্ণাকর্ণি গুণ করে বিয়োগ" → **ad − bc**
> a ও d = প্রধান কর্ণ (গুণ করো)
> b ও c = বিপরীত কর্ণ (গুণ করে বিয়োগ করো)

> **ক্র্যামারের নিয়ম মনে রাখা:**
> x = Dₓ/D, y = Dᵧ/D
> Dₓ = x-এর কলামে ধ্রুবক বসাও; Dᵧ = y-এর কলামে ধ্রুবক বসাও
